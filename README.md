## 🚀 Cách chạy dự án
1. Clone hoặc tải project về máy.
2. Mở **Android Studio** -> **Open**.
3. Chọn thư mục bài tập muốn chạy.
4. Chờ Gradle đồng bộ (Sync) xong.
5. Kết nối thiết bị/máy ảo và nhấn **Run (Shift + F10)**.
